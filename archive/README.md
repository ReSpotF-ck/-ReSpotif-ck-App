# Archive

Files kept for reference only. Nothing in this folder is used by the build or by the in-app updater.

- `art/` – screenshots and icon inherited from Spotilol.
- `release-assets/` – signing notes and checksums of superseded releases (Spotif*ck 1.0.6 and 1.0.7, ReSpotif*ck 1.0.8). None of them have the member login. The old APK files themselves were removed; the newest builds are in `/release-assets`.
- `app-unused-res/` – resources the app no longer references: legacy pre-API-26 launcher bitmaps (minSdk is 26, so the adaptive icon is always used), the default Android Studio launcher foreground, and the Play Store icon export.
